## Overview

chipsynth MD models the Yamaha YM2612 OPN2 FM chip used in the Sega Genesis at cycle level, reproducing the six FM operators, SSG-EG envelope looping, and DAC ladder distortion of the original hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plogue chipsynth MD** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **OPN2 Emulation** | Six-operator FM synthesis matching YM2612 register-level behavior |
| **SSG-EG Looping** | Hardware-accurate envelope generator looping modes for metallic tones |
| **DAC Distortion** | Models the 9-bit PCM DAC ladder and reconstruction filter artifacts |
| **VGM Import** | Load VGM chiptune files to study and modify Genesis sound programs |
